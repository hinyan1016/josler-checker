# J-OSLER 病歴要約チェッカー（Web版）

内科専門医制度 J-OSLER の病歴要約を、**ブラウザだけで**自己点検できる非公式の支援ツールです。

👉 **公開URL: https://hinyan1016.github.io/josler-checker/**

## 特長

- **完全オフライン・単一HTML**。入力した病歴要約は**このブラウザ内だけで処理され、サーバには送信されません**。
- 形式・PII（個人情報）・文字数・略語・薬剤名・用語を**機械チェック**して致命/警告/情報で色分け表示。
- PDF取り込み、登録略語一覧、サンプル（架空のデモ）。
- **🧠 AIレビュー依頼／✍️ AI修正版依頼**：6視点＋文献の実在確認を指示するプロンプトを生成（基本情報の個人情報は送信前に自動除外）。
  生成AI（ChatGPT/Gemini/Claude）に貼り付けて使います。

## ⚠️ 利用上の注意

- 医療従事者向けの**教育・自己点検支援**ツールです。診断・治療・患者管理に用いるものではありません。
- 結果は機械的な目安であり、**最終判断は指導医など人が**行ってください（検出漏れ・誤検出があり得ます）。
- 入力データはブラウザ内のみで処理されますが、**AIボタンで作ったプロンプトを生成AIに貼ると外部送信**になります。本文の匿名化は利用者の責任で行ってください。
- 本ツールは**日本内科学会・J-OSLER とは無関係**の非公式ツールです。登録略語一覧も公式の確定リストではありません。
